# LAST CONTACT — 3D aircraft models (Sketchfab, CC BY 4.0)

Each folder holds `model.glb` as downloaded. CREDITS.json: title, author, source URL, license.
Rules: always credit the author in the video description ("3D model: <title> by <author> (Sketchfab), CC BY 4.0").
Airline/brand liveries must be neutralized before use (render with textures removed — see previews.jpg "clean"),
except models that are already plain white (b767, citationx).
Known issues: c172 includes tie-down chains/blocks (hide those meshes); b777 and some others need scaling (units differ).
